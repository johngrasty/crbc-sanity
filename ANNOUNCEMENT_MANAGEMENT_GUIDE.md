# Announcement Management Guide

This guide will help church staff manage announcements in the Sanity Studio.

## Accessing Announcements

1. Log into Sanity Studio
2. Navigate to **Announcements** in the left sidebar
3. You'll see several filtered views:
   - **All Announcements** - View all announcements
   - **Active Announcements** - Currently displaying on the website
   - **Scheduled Announcements** - Set to display in the future
   - **Expired Announcements** - Past announcements that are no longer showing
   - **Inactive Announcements** - Announcements that have been turned off

## Creating a New Announcement

1. Click **Announcements** → **All Announcements**
2. Click the **+** button or **Create** button
3. Fill in the required fields:

### Content Tab (Main Information)

- **Title** (Required): The main headline for your announcement
  - Keep it concise (under 100 characters)
  - Example: "Easter Service Schedule"

- **Slug** (Required): Auto-generated URL-friendly version of the title
  - Click "Generate" to create automatically
- **Description** (Required): Brief summary for the carousel
  - Keep it between 100-150 characters
  - This appears in the homepage carousel
  - Example: "Join us for special Easter services on April 20th at 9am and 11am"

- **Featured Image**: Upload an image for the carousel
  - Recommended size: 1200x600 pixels
  - Use high-quality images that represent the announcement
  - Click the hotspot tool to adjust the focal point

- **Full Content**: Detailed information (optional)
  - Use this if the announcement has a dedicated page
  - Add formatted text, images, and links

- **Call to Action Text**: Button text (optional)
  - Examples: "Learn More", "Register Now", "Sign Up"
  - Keep it under 30 characters

- **Call to Action Link**: URL for the button (optional)
  - Only appears if you add CTA text
  - Can be internal (/ministries/crkids) or external (https://...)

### Settings Tab

- **Featured**: Toggle to feature prominently on homepage
  - Featured announcements get a star badge ⭐

- **Priority**: Number from 1-10 (default: 5)
  - Higher numbers appear first in the carousel
  - Use 8-10 for urgent announcements
  - Use 1-3 for less important updates

- **Active**: Toggle to show/hide immediately
  - Turn off to hide without deleting
  - Useful for temporarily removing announcements

### Scheduling Tab

- **Start Date** (Required): When to begin showing the announcement
  - Defaults to current date/time
  - Set future dates for scheduled announcements

- **End Date**: When to stop showing the announcement (optional)
  - Leave blank for announcements without an expiration
  - Must be after the start date

## Understanding Announcement Status

The preview shows status indicators:

- **✅ Active**: Currently displaying on the website
- **⏰ Scheduled**: Will display in the future
- **⏹️ Expired**: End date has passed
- **⏸️ Inactive**: Manually turned off

## Best Practices

### Timing

- Create announcements at least 1 week before they need to go live
- Set end dates for time-sensitive announcements
- Review expired announcements monthly and archive or delete

### Content

- Use clear, action-oriented titles
- Keep descriptions brief and scannable
- Include high-quality images when possible
- Always add a call-to-action for events requiring registration

### Priority Guidelines

- **Priority 9-10**: Emergency announcements, service cancellations
- **Priority 7-8**: Major events, special services
- **Priority 5-6**: Regular announcements, ministry updates
- **Priority 3-4**: General information, reminders
- **Priority 1-2**: Low-priority updates

### Organization

- Use the filtered views to manage announcements by status
- Archive or delete old announcements to keep the list clean
- Use consistent naming conventions for easy searching

## Previewing Announcements

Before publishing, you can preview how your announcement will look on the live website:

1. Make sure you've added a **slug** to your announcement (click "Generate" if needed)
2. Click the **Preview** button (eye icon) in the document toolbar
3. A new tab will open showing your announcement as it will appear on the website
4. You'll see a yellow banner at the top indicating you're in preview mode
5. Check that images, text, and buttons display correctly
6. Make adjustments in Sanity Studio as needed
7. Refresh the preview tab to see your changes
8. Click "Exit Preview" when you're done to return to normal viewing mode

**Note:** Preview mode works for both draft and published announcements, so you can see changes before making them live.

## Publishing Workflow

1. **Create** the announcement with all content
2. **Set** the appropriate priority and dates
3. **Preview** to verify it looks correct
4. **Publish** by clicking the green Publish button
5. **Verify** on the live website that it appears correctly

## Troubleshooting

### Announcement not showing on website

- Check that **Active** is toggled ON
- Verify **Start Date** is in the past
- Confirm **End Date** hasn't passed (if set)
- Make sure the announcement is published (green dot)

### Announcement in wrong order

- Adjust the **Priority** number
- Higher priority announcements appear first
- Check other announcements' priorities for comparison

### Image not displaying

- Verify image was uploaded successfully
- Check image file size (should be under 5MB)
- Try re-uploading the image
